FLIGHTKIT — TOOLS & TECH STACK OVERVIEW

=== LANGUAGE / RUNTIME ===

Python 3.10+
  Supported range is 3.10–3.13 (CI tests all of them). Local dev pins 3.10 in
  .python-version so you notice immediately if you use newer-only syntax.

uv
  Env, dependency, and lockfile manager. uv.lock pins the DEV/CI environment only —
  users installing flightkit from PyPI never see it; they get the ranges in pyproject.

=== PACKAGING ===

src/ layout
  Package lives in src/flightkit, so tests import the INSTALLED package, not the
  working directory — packaging mistakes show up in tests instead of for users.

hatchling
  Build backend ([build-system] in pyproject). Turns the source into a wheel/sdist.
  This is what makes `pip install -e .` and `uv build` work.

Extras (optional dependencies)
  api -> fastapi + uvicorn, mcp -> mcp, all -> both. Plain `pip install flightkit`
  pulls only httpx + pydantic.

py.typed
  Empty marker file (PEP 561). Without it, users' type checkers ignore our type hints.

=== RUNTIME DEPENDENCIES ===

httpx
  Async/sync HTTP client used by adapters to call external APIs (Zerolook, live fares).

Pydantic v2
  Typed models for requests/responses; validates API data on the way in.

=== OPTIONAL (EXTRAS) ===

FastAPI + Uvicorn  [api]
  Thin HTTP wrapper around core (src/flightkit/entrypoints/api.py).

mcp  [mcp]
  Official MCP Python SDK — exposes flightkit as tools to AI agents
  (src/flightkit/entrypoints/mcp_server.py, launched via the `flightkit-mcp` command).

=== ARCHITECTURE ===

Ports and adapters (hexagonal)
  core/ holds pure logic and defines Protocols (core/ports.py) for what it needs.
  adapters/ implement those Protocols against real services. entrypoints/ call into
  core. core never imports adapters, entrypoints, httpx, fastapi, or mcp —
  enforced by tests/test_architecture.py.

=== DEV TOOLING ===

Ruff
  Linter + formatter in one tool.

mypy (strict)
  Static type checking. Strict because SDK users rely on our types for autocomplete
  and their own type checking.

pytest / pytest-asyncio
  Test runner; asyncio_mode=auto lets async test functions run without decorators.

respx
  Mocks httpx requests in tests, so adapter tests never hit the network.

pre-commit
  Runs Ruff before every commit.

pip-audit
  Scans dependencies for known CVEs, locally and in CI.

=== CI/CD ===

GitHub Actions (.github/workflows/ci.yml)
  test          — base install on Python 3.10–3.13: ruff, mypy, pytest.
  test-extras   — all extras installed: mypy + pytest over the entrypoints.
  audit-and-build — pip-audit + uv build (catches packaging mistakes).

Dependabot
  Weekly PRs for uv dependencies and GitHub Actions.
